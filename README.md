# HB Gadget Website

Static e-commerce-style starter website for **HB Gadget**, a Bangladesh-based shop for mini speakers, gift boxes, mobile accessories, desk gadgets, and daily-use gadgets.

## Current repository

```text
https://github.com/hanifbhuian/hbgadgetbd
```

## Expected GitHub Pages URL

Because this is a project repository under the `hanifbhuian` account, the default GitHub Pages URL will be:

```text
https://hanifbhuian.github.io/hbgadgetbd/
```

This does **not** overwrite the personal website at `https://hanifbhuian.github.io/`. It is a separate project site using the `/hbgadgetbd/` path.

For a cleaner business URL later, you can connect a custom domain such as `hbgadgetbd.com` or create/transfer to an organization named `hbgadgetbd`.

## Publish steps

1. Go to repository **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/root`.
4. Click **Save**.
5. Wait a few minutes for GitHub Pages to publish.

## What to edit first

In `assets/js/app.js`:

- Replace `8801XXXXXXXXX` with the real WhatsApp number.
- Update product names, prices, descriptions, and categories.

In `index.html`:

- Replace phone, email, and contact information.
- Update text if you want Bangla/English mixed content.

## Notes

This starter site is static. It has product browsing, cart behavior using browser storage, and WhatsApp ordering. It does not include a real payment gateway, stock database, admin panel, or order-management backend.
Site deployment trigger.
